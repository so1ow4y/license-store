# init-скрипты Postgres

Пусто намеренно.

Расширения (citext, pgcrypto, pg_trgm, pg_stat_statements) создаёт Prisma
через `extensions` в datasource — см. `apps/api/prisma/schema.prisma`.
Если создавать их здесь, Prisma при каждой пересборке БД видит расширения,
которых нет в истории миграций, считает это дрейфом схемы и требует reset.

Правило: всё состояние БД описывается миграциями и ничем больше.
Сюда кладём только то, что миграциями выразить нельзя.
